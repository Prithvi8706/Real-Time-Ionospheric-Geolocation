# F10.7 OMNIWeb Auto-Lookup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a `/locate` caller omits `f107`, resolve it automatically from NASA OMNI2 data for the request date (cached per date, fail-soft to the 130.0 SFU default), per TODOS.md item 4.

**Architecture:** A new small module `api/f107.py` owns the lookup: `resolve_f107(explicit, dt)` returns `(value, source)` where source ∈ {"caller", "omniweb", "default"}. On first miss it downloads the yearly `omni2_{year}.dat` file (same URL and column positions as `data/fetch_omni.py`), parses the daily F10.7 for every day of that year into an in-process cache, and remembers failed years so an offline/air-gapped deployment degrades to the default exactly once per year-key, not per request. `api/main.py` makes `f107` Optional, resolves it in the endpoint, and reports `f107_used`/`f107_source` in the response (the same audit-trail convention as `selected_model` vs `model_used`).

**Tech Stack:** Python stdlib (`urllib.request`), pydantic/FastAPI, pytest with mocked fetch. Test interpreter: `"C:\Users\prith\anaconda3\python.exe"`.

## Global Constraints

- OMNI2 source: `https://spdf.gsfc.nasa.gov/pub/data/omni/low_res_omni/omni2_{year}.dat`; whitespace-delimited hourly rows; fields (0-indexed) 0=year, 1=day-of-year, 2=hour, 50=F10.7 daily SFU; fill values ≥ 999.0 are invalid (identical to `data/fetch_omni.py`).
- F10.7 is a **daily** value: cache key is the calendar date; one hourly row per day suffices.
- Fallback default stays **130.0 SFU** (the D9 training-time value); the existing 50–300 SFU validity range still applies to explicit values, and looked-up values outside it are discarded (→ default).
- Fail soft: any fetch/parse failure logs a warning and returns the default — `/locate` must keep working fully offline (air-gapped deployment is a documented feature).
- Network timeout 10 s; a failed year is not re-fetched within the process lifetime.
- Backward compatible: omitting `f107` works (now auto-resolves), supplying a value works unchanged, supplying an invalid value still returns HTTP 422.
- **Do not modify** `models/` (wiring f107 into the ionospheric models is separate deferred work — TODOS.md: "No other files need to be touched for this task").
- Commit messages: plain conventional commits, no attribution lines.
- Run tests from repo root: `"C:\Users\prith\anaconda3\python.exe" -m pytest tests/ -q`.

```python
"""
F10.7 solar-flux auto-lookup from NASA OMNI2 (TODOS item 4).

When a /locate caller omits f107, resolve_f107() fetches the yearly OMNI2
file for the request date, parses the daily F10.7 column, and caches every
day of that year in-process. Any failure (offline, air-gapped, bad data)
falls back to the 130.0 SFU training-time default — the service never
blocks on this lookup beyond one fetch attempt per year.

Column positions and fill-value handling match data/fetch_omni.py.
"""

import logging
import urllib.request
from datetime import date, datetime, timedelta

logger = logging.getLogger(__name__)

DEFAULT_F107 = 130.0
OMNI2_URL = "https://spdf.gsfc.nasa.gov/pub/data/omni/low_res_omni/omni2_{year}.dat"
FETCH_TIMEOUT_S = 10

# F10.7 is a daily value: cache key = calendar date.
_cache: dict = {}
_failed_years: set = set()


def _fetch_year(year: int) -> str:
    """Download the raw OMNI2 hourly file for one year (network touchpoint)."""
    url = OMNI2_URL.format(year=year)
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    with urllib.request.urlopen(req, timeout=FETCH_TIMEOUT_S) as resp:
        return resp.read().decode("ascii", errors="replace")


def _parse_year_into_cache(year: int, raw: str) -> None:
    """Store one F10.7 value per calendar day; skip OMNI fill values (>=999)."""
    jan1 = date(year, 1, 1)
    for line in raw.splitlines():
        parts = line.split()
        if len(parts) < 51:
            continue
        try:
            row_year = int(parts[0])
            doy = int(parts[1])
            f107 = float(parts[50])
        except (ValueError, IndexError):
            continue
        if row_year != year or f107 >= 999.0 or not (50.0 <= f107 <= 300.0):
            continue
        day = jan1 + timedelta(days=doy - 1)
        if day not in _cache:
            _cache[day] = f107


def lookup_f107(day: date):
    """Daily F10.7 (SFU) for `day`, or None if unavailable."""
    if day in _cache:
        return _cache[day]
    if day.year in _failed_years:
        return None
    try:
        raw = _fetch_year(day.year)
    except Exception as e:
        logger.warning("OMNI2 F10.7 fetch failed for %d (%s: %s) — "
                       "using default until restart", day.year, type(e).__name__, e)
        _failed_years.add(day.year)
        return None
    _parse_year_into_cache(day.year, raw)
    if day not in _cache:
        # fetched fine but this date has no usable value — don't refetch
        _cache[day] = None
    return _cache[day]


def resolve_f107(explicit, dt: datetime):
    """
    Resolve the F10.7 to use for a request.

    Returns (value, source): source is "caller" when supplied explicitly,
    "omniweb" when looked up by date, "default" otherwise.
    """
    if explicit is not None:
        return explicit, "caller"
    value = lookup_f107(dt.date())
    if value is not None:
        return value, "omniweb"
    return DEFAULT_F107, "default"
```
